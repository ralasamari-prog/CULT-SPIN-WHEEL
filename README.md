# CULT — Third Anniversary

صفحة احتفال كالت بالسنوية الثالثة، مناسبة للآيباد بالوضعين الطولي والعرضي.

## التشغيل

موقع ثابت بدون تبعيات أو خطوة بناء. افتح `index.html` أو شغّله بواسطة أي خادم ملفات ثابتة.

## النشر

استورد هذا المستودع في Vercel كموقع ثابت (Other). ملفات الموقع موجودة في جذر المستودع. لا يحتاج مفاتيح أو متغيرات بيئة أو قاعدة بيانات.
